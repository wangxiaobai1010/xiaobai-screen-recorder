## 3. ARCHITECTURE CONTRACT

`WorkerLoop` 在处理每帧前更新 visibility；`ProcessPendingFrame` 已无 visibility 早退。剩余前置早退仅处理非法 geometry、空尺寸或 frame-pool 尺寸变化，均与窗口可见性无关。

真实生产顺序为：source GPU copy → OutputCanvas clear/crop/camera draw → cursor composition → 单次 `RenderFrameTap::ObserveAndCopy`。`presentationEnabled=false` 的返回点位于 Tap 之后；仅 Preview back-buffer clear、letterbox draw 和 `Present` 被跳过。未发现第二套 capture/render/recording 路径。

## 4. FRAME OWNERSHIP

- 成功处理的 WGC frame 在一次 `RenderFrame` 后显式 `Close` 一次；geometry/size 早退也显式 Close。
- FrameArrived 的 single-pending replacement、Stop 后拒收及异常路径由 C++/WinRT/RAII 释放唯一 frame 引用；无共享裸 frame pointer。
- Tap 对 OutputCanvas 做 recorder-owned GPU copy；每次 `RenderFrame` 只有一个 Observe 调用。隐藏分支不新增 Close、Copy、Tap 或 Encoder input。
- Tap queue/lease 在既有 mutex 下转换，Stop 后 drain/unregister；已有 Gate 1/2/3 的 copied=enqueued=returned，OutstandingAtShutdown=0、DoubleReturn=0、InvalidState=0。

未找到 double close、double Tap、重复 Encoder input、tap texture 泄漏或 hidden 分支遗漏 back-buffer/surface 归还的可达路径。

## 5. VISIBILITY / RESTORE RACES

- A：frame 已开始处理后窗口才 hidden，最多该帧仍执行一次尾端 Present；Tap 已先完成。下一 worker iteration 关闭 presentation，不截断 Recording。
- B：窗口 Show/Restore 发生在 visibility 采样之后，最多多跳过一帧 Preview；下一 iteration 直接复用既有 swap chain 恢复 Present。
- visibility 状态仅由唯一 Preview worker 写读，不参与 Recording、Capture 或 Encoder ownership；Show/Restore 不调用任何 Restart。
- Resize 在同一 worker、visibility 和 frame processing 之前串行应用；没有 renderer surface 的并发重建。

## 6. STOP / SHUTDOWN RACES

- Stop Recording 与 Observe 并发时，Tap mutex/原子 stop 状态保证：已先入队的帧被 drain；Stop 先到则当前 Observe 丢弃，不会在 Unregister 后交付 lease。
- Preview Stop 先禁止 FrameArrived、设置 stop，再 join 唯一 worker；worker 完成至多一个已取得的 frame 后退出。随后依次 StopAndJoin Encoder、Shutdown Tap、清空 D3D state/resources。
- CallbackGate 在关闭 session/frame-pool 前 deactivate-and-wait；pending slot 随后清空。未发现 callback-after-free、stale surface、锁顺序环或 Finalize 重入。
- Preview 专属 Present 错误发生在 Tap 之后；device-removed 表示共享 D3D device 已失效，不能安全继续 Encoder。有效 HWND 的 minimize/hide 路径不调用 Present；Close/无效 HWND 语义仍归 P2.7C。

## 7. GPU / PRESENT BEHAVIOR

hidden/minimized 仍执行录制必需的 source copy、OutputCanvas/crop/camera/cursor 合成及 Tap copy；在 Preview RTV clear、Preview draw、Present 前立即返回。目标 GPU 边界正确，没有“只是不 Present但仍画 Preview back buffer”，也没有为省 Preview 工作而跳过成片合成。

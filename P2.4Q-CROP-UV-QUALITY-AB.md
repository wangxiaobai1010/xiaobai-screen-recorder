# P2.4Q Crop UV quality A/B

## Scope

This is a Windows-native quality regression harness. It does not enter the
product solution, public ABI, P/Invoke surface, UI, Preview runtime, or encoder
runtime. Test-only GPU readback is confined to `spikes/P2.4Q-CropUvQualityAB`.

The experiment holds the 1920x1080 BGRA source, product HLSL, linear-clamp
sampler, viewport, identity camera, OutputCanvas format, product
`D3D11Nv12Converter`, product `MfH264SinkWriterSession`, 8 Mbps target, 60 FPS,
120-frame GOP/input sequence, BT.709 settings, and Source Reader decode path
constant. The only A/B variable is the Crop UV constant.

## Pixel-center derivation

Let source width be `S`, crop left be `L`, crop width be `C`, output width be
`O`, and output pixel index be `i`. D3D11 rasterization evaluates the pixel
shader at output pixel centers, so the interpolated local UV is:

`u = (i + 0.5) / O`

Texture texel `x` has normalized center `(x + 0.5) / S`.

The product baseline endpoints are the first and last texel centers:

`originA = (L + 0.5) / S`

`scaleA = (C - 1) / S`

Therefore the sampled coordinate is:

`sampleA(i) = originA + u * scaleA`

For Wide (`L=0`, `C=O=S`), in texel-index space this is
`sampleA(i)*S - 0.5 = i + 0.5 - (i + 0.5)/S`. The first output pixel samples
near input index `0.4997`, the middle approaches its corresponding texel, and
the last samples near `S-1.4997`. Linear sampling therefore blends neighbors.

The candidate treats the half-open crop rectangle as texture edges:

`originB = L / S`

`scaleB = C / S`

`sampleB(i) = originB + u * scaleB`

When `O=C`, this simplifies to `(L+i+0.5)/S`, exactly the center of source
texel `L+i`. For 1920-wide full-screen Wide:

- first pixel: `(0.5)/1920` -> texel 0 center;
- middle pixel `i=960`: `(960.5)/1920` -> texel 960 center;
- last pixel `i=1919`: `(1919.5)/1920` -> texel 1919 center.

This covers the complete source without sampling outside `[0,1]` and preserves
the half-open crop rectangle. After the controlled A/B confirmed the root
cause, Candidate B was changed to call the product
`XbPreview.Native/CropTransform.h::ResolveCropTransform`; it is no longer a
second handwritten copy of the candidate formula. Baseline A retains the old
formula solely as historical evidence.

## Evidence and decision

Each run creates a non-governed directory under
`artifacts/p2.4-quality-ab/crop-uv/<run-guid>`. `metrics.json` contains whole
frame and ROI measurements; `quality-ab-report.md` contains the run-specific
decision; `index.html` links the unscaled native files. Test artifacts do not
replace product acceptance evidence and are excluded from formal governance.
